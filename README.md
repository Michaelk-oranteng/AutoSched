AutoSched ⏱️
Automate your scheduling, reclaim your time.

AutoSched is a smart scheduling tool that automatically finds the best meeting times across multiple calendars, users, and time zones. Say goodbye to back-and-forth emails and double-bookings.

✨ Features
Smart Time Slots – Finds optimal meeting times based on availability, preferences, and priority.

Multi-Calendar Sync – Integrates with Google Calendar, Outlook, iCal, and more.

Time Zone Aware – Automatically adjusts for participants in different time zones.

Recurring Events – Schedule repeating meetings with intelligent conflict resolution.

Rules Engine – Set buffers, working hours, break times, and blackout periods.

REST API – Embed AutoSched into your own apps or bots.

🚀 Quick Start
Prerequisites
Python 3.9+ / Node.js 18+ (depending on your implementation)

API keys for calendar services (Google, Microsoft, etc.)
